## App Name

## Short Description (80 chars max)
Защищённый мессенджер Matrix с E2E шифрованием от Kiberos

## Full Description (4000 chars max)

Kiber.Chat — это безопасный мессенджер на базе протокола Matrix, созданный командой Kiberos.

### Основные возможности:

🔐 **Сквозное шифрование (E2E)**
Все сообщения защищены современным шифрованием. Никто, кроме участников беседы, не может прочитать ваши сообщения.

📞 **Голосовые и видеозвонки**
Звоните друзьям и коллегам с высоким качеством связи. Поддержка групповых звонков.

👥 **Групповые чаты и пространства**
Создавайте команды, сообщества и проекты. Организуйте общение с помощью пространств.

🔄 **Синхронизация между устройствами**
Ваши сообщения доступны на всех устройствах — телефоне, планшете и компьютере.

📁 **Обмен файлами**
Отправляйте фото, видео, документы и любые другие файлы.

🌐 **Федерация Matrix**
Общайтесь с пользователями любых серверов Matrix, не только kiber.chat.

### Почему Kiber.Chat?

• **Приватность** — ваши данные принадлежат только вам
• **Открытый код** — приложение полностью открыто (AGPL лицензия)
• **Надёжность** — построено на проверенном протоколе Matrix
• **Без рекламы** — мы не продаём ваши данные

### Технические детали

• Подключается к серверу matrix.kiber.chat
• Поддержка всех функций Matrix 1.0+
• Основано на Element X от Element.io
• Минимальная версия Android: 7.0
