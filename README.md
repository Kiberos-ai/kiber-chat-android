# Kiber.Chat Android

Secure Matrix messenger by [Kiberos](https://kiberos.ai).

This is a fork of [Element X Android](https://github.com/element-hq/element-x-android) with Kiberos branding.

## About

Kiber.Chat is a Matrix client that provides:
- End-to-end encrypted messaging
- Voice and video calls
- Group chats and spaces
- File sharing
- Cross-device sync

The app connects to the Kiberos Matrix homeserver at `matrix.kiber.chat`.

## Building

```bash
# Clone the repository
git clone https://github.com/Kiberos-ai/kiber-chat-android.git
cd kiber-chat-android

# Build debug APK
./gradlew assembleDebug

# Build release bundle
./gradlew bundleRelease
```
